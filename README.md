# Dictation-App 

![CI](https://github.com/victorpolitakis/dictation-app/actions/workflows/ci.yml/badge.svg)

A dictation app with enhanced multi-language code-switching and interactive triggering for Android devices

## How this is built
The backend is built in Python and it is separate from Kotlin and frontend implementations. An agent was by my side advising me for the next steps when stuck, but each git command, branch, pr, dependency and code was written and executed by me.

For Kotlin, AI Agents were used to create and check on their code. I designed the frontend using Claude Design.

## Background
This project is taking place in the current Winter Semester 2026-27 for the course "Software Development for Mobile Devices". It is a course assessment that doesn't require covering a specific theme, but it is designed to use creativity to bring interesting software, while also maintaining technical requirements.

I decided to create a dictation app for this project that currently has no name, coming from a background of tinkering with whisper models, podcast transcription for faster learning enhanced with LLMs, and a NotebookLM clone attempt from a previous course called "Processing Sound and Music" of a previous semester.
